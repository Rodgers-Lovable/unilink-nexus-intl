# Unilink Nexus Int'l

Build a complete, modern, responsive website for an international education consultancy called:

UNILINK NEXUS INTERNATIONAL

Brand tagline:

"Your Link to Global Opportunities"

The company helps students explore and pursue higher education opportunities abroad. The website should feel like a modern international education platform rather than a traditional consultancy brochure.

The core objectives of the website are:

1. Help prospective students understand what Unilink Nexus does.

2. Help students explore international study destinations.

3. Explain how Unilink supports students throughout the study-abroad journey.

4. Build credibility and trust.

5. Convert visitors into consultation leads.

6. Provide useful study-abroad resources.

7. Include an interactive preliminary Study Abroad Eligibility Assessment that can later be AI-powered.

8. Build the architecture so it can later evolve into a more advanced student guidance platform.

IMPORTANT:

Do not make the website look like an old-fashioned study-abroad agency.

Do not use excessive gradients, globes, flags, graduation caps, or generic student stock imagery everywhere.

Do not overload the design with all brand colors.

The website should be calm, premium, trustworthy, modern, spacious, and technology-enabled.

8. ELIGIBILITY ASSESSMENT

==================================================

Route:

/study-abroad/eligibility

This is one of the most important parts of the website.

Create a multi-step interactive wizard.

Do not make it look like a long traditional form.

Use a conversational progression.

At top:

"Study Abroad Eligibility Check"

Description:

"Tell us about your academic background and study goals to receive a preliminary assessment."

Progress indicator:

1. Goal

2. Education

3. Destination

4. Profile

5. Assessment

STEP 1 — STUDY GOAL

Question:

"What level would you like to study?"

Options:

- Bachelor's

- Master's

- PhD

- Diploma / Certificate

- Not sure yet

Question:

"What subject or field are you interested in?"

Use:

searchable field

with free-text fallback

STEP 2 — EDUCATION BACKGROUND

Ask:

"What is your highest completed qualification?"

Options:

- Secondary school

- Diploma

- Bachelor's degree

- Master's degree

- Other

Then dynamically ask:

- qualification name

- institution

- year completed

- grading system

- approximate grade/GPA

Make all forms user-friendly.

STEP 3 — DESTINATION

Question:

"Where would you like to study?"

Options from supported destinations.

Also provide:

"I'm not sure — help me decide"

Allow more than one preferred destination.

STEP 4 — STUDENT PROFILE

Ask:

- current country

- preferred intake

- English proficiency test status

- test type if applicable

- score if applicable

- approximate tuition budget

- any additional context

Budget should use ranges rather than force an exact figure.

STEP 5 — ASSESSMENT

For initial implementation:

Create deterministic mocked assessment logic.

Do NOT rely on a real AI API yet unless explicitly configured.

Output example:

Status

Example:

IMPORTANT DISCLAIMER:
